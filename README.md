# HyperTrack SDK for React Native

[![npm](https://img.shields.io/npm/v/hypertrack-sdk-react-native)](https://www.npmjs.com/package/hypertrack-sdk-react-native)

Add live location tracking to your React Native app on Android and iOS with the [HyperTrack](https://hypertrack.com) SDK.

```sh
npm install hypertrack-sdk-react-native \
  hypertrack-sdk-react-native-plugin-android-location-services-google \
  hypertrack-sdk-react-native-plugin-android-push-service-firebase
```

Follow the [React Native integration guide](https://hypertrack.com/docs/install-sdk-react-native) to configure the native SDKs and choose Android service plugins. See the [React Native quickstart](https://github.com/hypertrack/quickstart-react-native) for a working app.

For changes by version, see the [changelog](CHANGELOG.md) and [GitHub Releases](https://github.com/hypertrack/sdk-react-native/releases).
